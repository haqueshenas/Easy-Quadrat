2. Ultralytics YOLO and Easy Quadrat Model Weights
--------------------------------------------------

Auto Deep Learning uses the Ultralytics YOLO instance-segmentation
framework and trained model weights.

Built-in model files:
- models/easyquadrat.pt
  Easy Quadrat EQ1; documented in the v1.0 release as YOLOv8n-seg.

- models/easyquadrat2.pt
  Easy Quadrat EQ2; documented in the v1.0 release as YOLOv8m-seg.

- models/EQ_Frameless_1.pt
  Easy Quadrat Frameless model variant 1.

- models/EQ_Frameless_2.pt
  Easy Quadrat Frameless model variant 2.
